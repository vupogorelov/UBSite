# UBSite — Urantia Papers Explorer

Перед работой над новой функцией прочитать **VISION.md**. Центральная цель: изучать Книгу Урантии как человека
(читать, слушать, общаться, узнавать, записывать мысли, делиться); позже ИИ станет собеседником-Книгой.
Каждое решение проверяется по принципам и вопросам из VISION.md.

Другие документы:
- DESIGN.md — правила интерфейса;
- TODO.md — идеи, бэклог и шаги стратегии;
- DEPLOY.md и HOSTING.md — запуск и хостинг.

Общение с автором — по-русски. Зависимостей минимум. Большие шаги сначала обсуждаются.
